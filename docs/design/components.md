# Component contract: ContractTracker

Generated by `design-system` from `docs/design/tokens.json`
v1. Every component below consumes tokens by role name and
nothing else. A component that needs a value the tokens do not have
gets a new token in `tokens.json`, never a literal.

Conventions used in every entry:

- Sizes: `sm` 32px, `md` 40px, `lg` 48px control height on web and
  desktop; mobile controls are `md` or `lg` (44pt minimum touch target).
- States: `rest`, `hover` (pointer devices only), `focus-visible`,
  `active`, `disabled`, `loading`, and where relevant `selected`,
  `invalid`, `checked`, `indeterminate`.
- Elevation: level 1 at rest and level 2 on hover for pressables;
  level 3 for overlays; 0 for everything else (the elevation rule).
- Focus: `focus.width` ring in the `focus` role with `focus.offset`,
  drawn with `outline`, never removed.
- Motion: state changes use `duration.fast` with `easing.standard`;
  entrances use `duration.base` with `easing.enter`; exits
  `duration.fast` with `easing.exit`; all zero under reduced motion.

This is the Ledger direction (`docs/design/variants/react-ui/README.md`): 2px corners, ruled
rows, no shadows on static blocks. Entries below are the kit's contract trimmed to what the app
has; Dialog, Sheet, Toast, Navigation, Checkbox and radio, List row and Skeleton are cut because no
screen uses them. The status badge, the notice line and the quote are app parts the page does not draw yet.

## Button

- Variants: `primary` (one per view), `secondary`, `ghost`, `danger`,
  `link`. Icon-only is a modifier, not a variant.
- Sizes: `sm`, `md`, `lg`.
- States: rest, hover, focus-visible, active, disabled, loading.
- Tokens: `accent`, `accent-hover`, `accent-active`, `on-accent`
  (primary); `surface`, `text`, `border-strong` (secondary); `danger`,
  `on-danger` (danger); `link` (link); `radius.control`; `space.2`
  horizontal padding at `sm`, `space.3` at `md` and `lg`; `font.roles.label`;
  `elevation.1` rest, `elevation.2` hover, `elevation.0` ghost and link.
- Accessibility: a real `button` (or `a` with `href` for link);
  icon-only carries `aria-label`; loading sets `aria-busy` and keeps the
  label; disabled stays focusable when it explains why (tooltip) and is
  otherwise removed from the tab order.
- Do: label with the verb and the object ("Save invoice"). Keep the
  same label through the flow.
- Do not: put two primaries in one view; animate width on hover; use
  `title` as the only label.
- In this app: `data-slot="button"`, `data-slot="tab"` in `web/src/App.tsx` and `web/src/panels.tsx`. One size (min-height 44px); the primary is the ink-green accent.

## Input

- Variants: `text`, `email`, `number`, `password`, `search`, `textarea`,
  with optional leading icon, trailing action, prefix and suffix.
- Sizes: `sm`, `md`, `lg`.
- States: rest, hover, focus-visible, disabled, read-only, invalid.
- State notes: invalid always shows its error text; rest may show
  helper text.
- Tokens: `surface`, `text`, `text-muted` (placeholder and helper),
  `border`, `border-strong` (hover), `focus`, `danger` (invalid border
  and error text), `radius.control`, `space.2` padding, `font.roles.body`.
- Accessibility: a visible `label` bound by `for`; error text linked with
  `aria-describedby` and `aria-invalid="true"`; never placeholder as the
  label; `autocomplete` set for personal fields; `inputmode` for numeric.
- Do: show the error next to the field on blur and clear it on input.
- Do not: shift layout when the error appears (reserve the line);
  colour alone as the error signal.
- In this app: `data-slot="input"` with `data-slot="label"` in `web/src/panels.tsx` (upload, the question box, the date).

## Select

- Variants: native `select` for under 8 options; listbox with search for
  more; multi-select renders chosen items as removable chips.
- Sizes: `sm`, `md`, `lg`.
- States: rest, hover, focus-visible, open, disabled, invalid.
- Tokens: as Input, plus `surface-raised` and `elevation.3` for the
  popup, `accent-subtle` for the highlighted option, `radius.overlay`
  for the popup, `z.overlay`.
- Accessibility: native select where possible; custom listbox follows
  the APG combobox pattern (`role="combobox"`, `aria-expanded`,
  `aria-activedescendant`, arrow keys, type-ahead, Escape closes).
- Do: keep the popup within the viewport; return focus on close.
- Do not: open on hover; trap focus in a non-modal popup.
- In this app: `data-slot="select"` in `web/src/panels.tsx` (the contract picker).

## Card

- Variants: `static` (a grouping surface) and `pressable` (the whole
  card is one link or button).
- Sizes: padding `space.3` compact, `space.4` default.
- States: rest, hover, focus-visible, active.
- State notes: a static card has rest only; the others are pressable.
- Tokens: `surface`, `border`, `radius.container`; `elevation.0` for
  static, `elevation.1` and `elevation.2` for pressable.
- Accessibility: a pressable card is one `a` or `button` covering the
  card with the heading as its name; nested interactive elements are
  not allowed inside a pressable card.
- Do: use a card when the group needs a boundary the layout does not
  already give.
- Do not: build a page out of stacked cards; put a shadow on a static
  card; nest cards.
- In this app: `data-slot="panel"`: a ruled block, not a shadowed card (the Ledger direction has no shadows).

## Table

- Variants: `data` (sortable, selectable), `simple` (read-only).
- Sizes: row height `sm` 36px, `md` 44px.
- States: rest, hover, selected, sorted-asc, sorted-desc, loading, empty, error.
- State notes: rest, hover and selected are per row; sorted-asc and
  sorted-desc per header; loading (skeleton rows), empty and error per
  table.
- Tokens: `surface`, `bg-subtle` (header), `border` (row divider),
  `accent-subtle` (selected), `font.roles.label` for headers,
  `font.roles.body` with tabular figures for cells, `space.2` cell
  padding.
- Accessibility: a real `table` with `th scope`; sort buttons inside
  headers with `aria-sort`; a caption or `aria-labelledby`; row
  selection through a checkbox column with a header select-all.
- Do: right-align numbers; keep the first column sticky on narrow
  screens; page or virtualise above 200 rows.
- Do not: collapse a table into cards below `md` without keeping the
  headers as labels; hide actions behind hover only.
- In this app: `data-slot="table"` in `web/src/panels.tsx`: ruled rows, right-aligned figures, status badges in cells.

## Tabs

- Variants: `line` (underline indicator), `segmented` (pill group,
  up to 4 items), `pill` for filters.
- Sizes: `sm`, `md`.
- States: rest, hover, focus-visible, selected, disabled.
- State notes: per tab.
- Tokens: `text-muted` rest, `text` selected, `accent` indicator,
  `bg-subtle` segmented track, `surface` segmented selected,
  `duration.fast` indicator move (transform only).
- Accessibility: `role="tablist"`, `role="tab"` with `aria-selected`
  and `aria-controls`, `role="tabpanel"` with `aria-labelledby`; arrow
  keys move, Home and End jump, activation is automatic for `line` and
  `segmented`, manual (Enter) when panels load data.
- Do: reflect the selected tab in the URL when the page is shareable.
- Do not: use tabs for sequential steps; nest tabs.
- In this app: `data-slot="tablist"` and `data-slot="tab"` in `web/src/App.tsx`.

## Empty state

- Variants: `first-run` (nothing yet, with a primary action),
  `no-results` (a filter or search found nothing, with a clear action),
  `error` (with retry).
- Sizes: `inline` (inside a panel) and `page`.
- States: first-run, no-results, error.
- State notes: one per variant; the empty state itself does not change.
- Tokens: `text` heading, `text-muted` body, `space.5` vertical
  rhythm, an illustration at most 160px using `accent-subtle` and
  `text-muted` only.
- Accessibility: heading level continues the page outline; the action
  is a Button; an error variant is announced through `role="status"`.
- Do: say what is missing and what to do next, in the product's
  voice.
- Do not: apologise; show a lonely icon with no action; use the
  error variant for an empty list.
- In this app: `data-slot="empty"` in `web/src/ui.tsx`.
